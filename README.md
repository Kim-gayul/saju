# 결 · 나의 사주 이야기
<img src=assets/saju-promo.png>

생년월일과 시간을 입력하면 절기 기반 사주 원국을 계산하고 OpenAI 모델이 한국어로 풀이하는 작은 웹 앱입니다. 상단 메뉴에서 사주풀이, 오늘의 운세, AI 상담을 전환할 수 있습니다. 사주풀이를 완료하면 그 원국을 바탕으로 AI 상담을 이어갈 수 있습니다. 상담 기록은 브라우저 탭의 메모리에만 남으며 새로고침하면 사라집니다.

## 실행

Node.js 20.12 이상이 필요합니다.

```powershell
npm install
Copy-Item .env.example .env
# .env 파일의 OPENAI_API_KEY 값을 자신의 키로 바꾸세요.
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 서버는 프로젝트 루트의 `.env` 파일을 시작할 때 읽습니다. 파일을 수정한 뒤에는 서버를 재시작하세요. API 키가 없어도 원국과 오행은 볼 수 있고, AI 풀이는 키를 설정한 뒤 활성화됩니다. 모델은 `OPENAI_MODEL` 환경 변수로 바꿀 수 있습니다.

## 계산 및 주의사항

- 양력과 음력(윤달 포함)을 지원합니다. 입력한 출생지는 한국 표준시 기준으로 간주합니다.
- 출생 시간을 모르면 시주를 제외합니다.
- 절기 경계, 자시 일주 구분 등은 만세력 서비스마다 다를 수 있습니다. 중요한 경우 전문 만세력과 대조하세요.
- 오행 막대는 네 기둥의 천간과 지지 표면 오행만 집계합니다.
- 풀이 결과는 전통 문화 기반 참고용 콘텐츠입니다.
- 이름과 출생 정보는 이 서버에 저장하지 않지만, 풀이를 위해 OpenAI API로 전송됩니다.
