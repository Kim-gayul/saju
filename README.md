# 결 · 나의 사주 이야기
<img src=assets/saju-promo.png>

생년월일과 시간을 입력하면 절기 기반 사주 원국을 계산하고 OpenAI 모델이 한국어로 풀이하는 작은 웹 앱입니다.

## 실행

Node.js 20 이상이 필요합니다.

```powershell
npm install
$env:OPENAI_API_KEY="sk-..."
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. API 키가 없어도 원국과 오행은 볼 수 있고, AI 풀이는 키를 설정한 뒤 활성화됩니다. 모델은 `OPENAI_MODEL` 환경 변수로 바꿀 수 있습니다.

## 계산 및 주의사항

- 양력과 음력(윤달 포함)을 지원합니다. 입력한 출생지는 한국 표준시 기준으로 간주합니다.
- 출생 시간을 모르면 시주를 제외합니다.
- 절기 경계, 자시 일주 구분 등은 만세력 서비스마다 다를 수 있습니다. 중요한 경우 전문 만세력과 대조하세요.
- 오행 막대는 네 기둥의 천간과 지지 표면 오행만 집계합니다.
- 풀이 결과는 전통 문화 기반 참고용 콘텐츠입니다.
- 이름과 출생 정보는 이 서버에 저장하지 않지만, 풀이를 위해 OpenAI API로 전송됩니다.
